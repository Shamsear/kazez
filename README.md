  - Doha Showroom & Concierge Contact Desk

## 🛠️ Quick Start & Local Development

### Running the Storefront
```bash
cd frontend-light
npm install
npm run dev
```
*Access local dev server at `http://localhost:5174/` or `http://localhost:5175/`.*

### Production Build
```bash
cd frontend-light
npm run build
```
